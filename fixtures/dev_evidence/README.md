# Development evidence

This directory is frozen historical evidence from Stage 1. It is intentionally
not regenerated by `scripts/build_fixtures.py` and must not be modified.

`holdout_v1/` contains the original H01–H05 bundles, their labels and
`MANIFEST.sha256`, moved here unchanged after the Stage 1 review. The set was
inspected during debugging and `H03_spec_reordered` was regenerated after its
first run, so it cannot support an unbiased final evaluation. It is retained as
development evidence: `tests/integration/test_dev_evidence_stage1.py` compares
the pipeline against the recorded labels as ordinary regression tests.

Historical debugging entries in `docs/debugging_log.md` refer to the former
`tests/holdout/test_holdout_stage1.py` path; the file was moved, not deleted.

The sealed holdout reserved for final evaluation lives in `holdout/` at the
repository root and uses a separate claims-triage domain.
